
## 概述

整体链路：
1. ShowDialogEvent
2. DialogManagerFragment
3. HalfScreenPageContentFragment / BottomHalfScreenFragment / 其他半屏 Fragment
4. HalfScreenPageDataAdapter
5. HalfScreenPageDataRequest
6. 接口返回 PagePanel / Section / LineData
7. TiledHomeFragmentAdapter + HiveViewModel 上屏

## 半屏拉起的核心机制

### DialogManagerFragment

先用如下方法把` DialogManagerFragment` 添加到需要拉起半屏的activity的 `FragmentManager` 里
`DialogManagerFragment.enableDialogNow((FragmentActivity) activity, true);`

它不直接显示 UI，而是监听事件：
```java
@Subscribe(threadMode = ThreadMode.MAIN)
public void onShowDialogEvent(ShowDialogEvent event) {
    ...
    event.showFragment(fm, ft, mHalfContainerId);
}
```

半屏容器默认 ID 是 `R.id.cover_container`
注意：许多 xml 里没有直接写 cover_container
项目里是在 DialogManagerFragment.java 收到半屏事件时，如果 Activity 是 BaseActivity，会主动
((BaseActivity) getActivity()).initHalfContainer();，然后在检查，保证有容器布局

> PlayerDialogManagerFragment.java：
> 专用于播放器内部的半屏管理，处理OnePage改造之后，PlayerLayer内部的半屏无法正常添加的问题
>  时机： 
>  播放器全屏之后，启用此管理器，处理ShowDialogEvent， 
>  播放器恢复小窗后，禁用此管理器，恢复原有的从属于Page的DialogManagerFragment


### ShowDialogEvent

ShowDialogEvent中通过send方法post半屏显示事件，DialogManagerFragment回调处理，分两种情况：dialog和fragment

```java
public void showFragment(@NonNull FragmentManager fm, @NonNull FragmentTransaction ft, int containerId) {
    ft.addToBackStack(String.valueOf(mFragment.hashCode()));
    ...
    ft.add(containerId, mFragment);
    ft.commit();
    mShown = true;
}
```
+ 使用 add，不是 replace；
+ 会 addToBackStack，所以返回键可以关闭；
+ 如果容器里已有 fragment，会先 hide(prev)；
+ 生命周期销毁时会通知 DialogManagerFragment 从记录列表里移除。


### pullUpDialog

ConstantsAndUtils.java 的 pullUpDialog(...) 是拉起半屏的入口，他会根据actionId过滤一些拉起，然后通过actionId选择对应的create方式

```java 
// ConstantsAndUtils.java
if (action == null || (action.actionId != ActionId._ACTION_CHASE_CALENDAR
        && action.actionId != ActionId._ACTION_DETAIL_PLAYER_COVER_DESCRIPTION
        && ...)) {
    return false;


case ActionId._ACTION_DETAIL_EXTEND_PANEL:
    dialog = createExtendPanelFragment(coverId, isCharge, vid, title, action);
    dialogSupportAutoHide = true;
    break;

    
PlayerDialogManagerFragment.enableOrSuppressDialog(activity);
DialogManagerFragment.enableDialogNow((FragmentActivity) activity, true);
ShowDialogEvent.send(dialog, dialogSupportAutoHide, callback);
}
```

> 详情页DoubleRowDetail..中handleItemClicked里调用pullUpDialog拉起弹窗

### ExtendPanelFactory

ExtendPanelFactory.java 是分发工厂，根据参数决定创建哪种半屏
参数为ExtendType，其中的_ET_PAGE还分PanelPageType类型
这里最终会被分发为以下几种Fragment
+ HalfScreenCoverContentFragment
+ HalfScreenCoverProfileFragment
+ HalfScreenPageContentFragment

以HalfScreenPageContentFragment为例子，其中用HalfScreenPageDataAdapter请求数据



## 通用半屏


### 整体架构概览

+ 入口按钮（action: \_ACTION_DETAIL_EXTEND_PANEL + page_type）
+ HalfScreenPageContentFragment（识别 page_type，做差异化配置）
+ HalfScreenPageDataAdapter（请求/构造半屏数据）
+ HalfScreenUtils.getHalfSpecialMarginType() → LineDataHelper（设置列表 margin）
+ GridViewModel（消费 GridInfo，注冊自己的 XML 布局 + 子 ViewModel）
+ Component + ViewModel（HiveView 绘制）


### 改动清单

1. 定义半屏 page_type 常量（ActionArgs.java，由在actionArgs中映射下发）
2. 由后台下发（本地可mock测试）
	1. 入口按钮的 actionId 必须是 \_ACTION_DETAIL_EXTEND_PANEL（值为 246）
	2. actionArgs 里必须传 page_type(ACTION_ATTR_STR_PAGE_TYPE) 和 extend_type=4(ExtendType.\_ET_PAGE)
3. HalfScreenPageContentFragment 差异化适配
	1. onViewCreated() 里设置背景和返回提示
	2. setPanelReportInfo() 里设置大同上报面板名称
	3. onFixDataGet() 里清除列表 padding
4. HalfScreenUtils 注册 margin 类型，LineDataHelper 处理 margin
	1. 新枚举值
	2. 左右 margin 设置
	3. 底部 margin 设置
5. JCE 协议层
	1. 新增类型常量
	2. JCE 数据结构的字段扩展
	3. 类型转换注册
6. 创建 GridViewModel、 XML 布局、 Component
