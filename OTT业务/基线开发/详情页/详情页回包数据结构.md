## 针对详情页顶部功能按钮

> 以新版双列左右结构为例，老版本逻辑还有所不同（普通的详情页）
> `CoverHeaderViewModel`
  ├─ `CoverHeaderPlayerViewModel`
  └─ `CoverHeaderInfoViewModel`
        └─ `HeaderFuncBtnListViewModel`
              └─ `rtl_function_button_container`



先说一下常规的链路：
```java
// DoubleRowDetailCoverPageFragment.java
model.getDetailHeaderInfoLive().observe(getDataLifecycleOwner(), this::handleHeaderInfo);

private void handleHeaderInfo(@NonNull DetailHeaderInfo headerInfo) {
    mRefreshRateReporter.setInfoModuleData(headerInfo);
    mPlayerViewModel.updateViewData(headerInfo);
    mInfoViewModel.updateViewData(headerInfo);
}
```
这里只是影响左侧的播放器和信息区域，并不涉及到右上的功能列表

顶部功能按钮走的还是Unit/ListData体系:
DoubleRow 场景里，不再使用完整的 `CoverHeaderViewModel` 来一口气画整个头部，而是把头部拆成：
+ 左上播放器：`CoverHeaderPlayerViewModel`
+ 左下信息：`CoverPageInfoViewModel`
+ 右上功能按钮：`HeaderFuncBtnListViewModel`
	+ 右上按钮的独立布局是：`view_cover_header_function_button_list.xml`


从数据请求源头来捋顺：

1. 
	+ `DetailCoverInfoModel`的`getDetaiModel`创建`CoverDetailRootModel`
	+ `CoverDetailRootModel`创建url，并且`fireRequest`
2. 
	+ `CoverDetailRootModel`中的Response返回`CoverDetailPageContent`，然后创建`CoverPageModel`
	+ 其中的`addData`会把`CoverDetailPageContent`拆成`List<SectionInfo>`，然后`SectionDataModel.createWithInfo(sectionInfo)`创建`SectionDataModel`
	+ `SectionDataModel`的`setData`又会去拆成`GroupInfo`，得到`GroupDataModel`；在group这一层又被进一步拆解为：`UnitGroupDataModel`
	+ 进一步还会被处理得到`LineInfo`
3. 
	+ 在`AbsGroupDataModel`中的`createDataModel`方法里，会根据`LineType._LT_COVER_DETAIL_HEADER`解析得到`HeaderDataModel`
4. 
	+ 在`HeaderDataModel`里解析得到`CoverHeaderViewInfo`
	+ 这里如果是`doubleRowStyle`，会选择：`innerViewType = LocalViewTypeConvert.LVT_COVER_HEADER_FUNCTION_BUTTON`
	+ 然后创建`DetailHeaderInfo`，完成了`DetailHeaderInfo.buttons = CoverHeaderViewInfo.buttonList;`的转化
	+ `root.updateDetailHeaderInfo(mHeaderInfo);`通知外界setLiveData
	+ 然后创建右上功能按钮 Unit：`ViewInfoUnit<DetailHeaderInfo\`，其中`innerViewType = LVT_COVER_HEADER_FUNCTION_BUTTON`，对应`HeaderFuncBtnListViewModel`
	+ 此处的Unit等待`CoverDetailRootModel`收集
5. 
	+ `ViewInfoUnit<DetailHeaderInfo>` 会把 `DetailHeaderInfo` 传给对应 `HeaderFuncBtnListViewModel`
	+ viewModel的`updateFunctionButtons`方法里合并当前视频态按钮
6. 
	+ 等unit被收集后在`DoubleRowFragment`里被set到`mSideListAdapter`（`UnitAdapter`）
	+ 当 `RecyclerView` 需要创建某个 item 时，会通过 `UnitPreloader` 获取类型，然后在`TVViewModelFactory`里创建ViewModel（`HeaderFuncBtnListViewModel`）
	+ `UnitPreloader / UnitAdapter` 创建好 ViewModel 后，还会绑定数据，调`ViewInfoUnit`的`updateViewData`，这样子`HeaderFuncBtnListViewModel`就拿到数据去处理按键了
